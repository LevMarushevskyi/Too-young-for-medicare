## Stats-audit follow-up (about 14:25 ET)

After this pass I re-ran `make estimates model figures` (exit 0) and AppTest on all 4 pages against the real data (0 exceptions). Three output files changed: `meps_age_gap_tests.csv`, `meps_model_or.csv` and `ml_calibration.csv`, plus `models/model_card.json` (limitations only). Every other CSV is byte-identical to the earlier run, and no headline value moved.

- **Lonely PSU.** `survey.adjust.domain.lonely = TRUE` stays on as the primary MEPS setting. It is conservative and matches the team's script, and the README and Methods page now say so.
  - `meps_model_or.csv` has new `adjust_nodomain` rows with the domain adjustment off. The Model B under-65 aOR is 3.776 in every run.
  - Its 95% CI is 1.582–9.013 in the primary run, 1.748–8.158 with `adjust_nodomain`, and 1.571–9.076 with `average`.
  - The `average` rows vary only the lonely-PSU method, and the README now describes them that way.
- **Age-gap p vs CI.** `meps_age_gap_tests.csv` gains a `p_wald` column at the end, from the same svycontrast t-test as the CI.
  - prob_pay_bills: +8.1 pp (−0.8 to 17.1), p_wald 0.0743, Rao-Scott 0.029.
  - delay_or_forgo_care_cost: +5.3 pp (−1.0 to 11.7), p_wald 0.0998, Rao-Scott 0.0303.

  - worry_bills: p_wald 0.019. any_csaq_strain: p_wald 0.000693.
